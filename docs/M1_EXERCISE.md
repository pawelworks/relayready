# M1 acceptance exercise

The owner directed the project to use a self-created sanitized example and proceed to phase 2. `examples/acceptance/NOTES.md` captures the same project checkpoint as free-form notes; `examples/acceptance/HANDOFF.md` converts it to Stafeta 0.1.

## What fit

- Goal, completion criteria, standing prohibitions, verified state, completed work, rejected scope, next actions, human-only questions, and environment facts each had an unambiguous home.
- The invariant chain preserved all prohibitions verbatim.
- Absolute verification dates removed temporal ambiguity.
- Separating State from Done so far prevented test evidence from being confused with pending work.

## What did not fit exactly

- Version 0.1 has no dedicated field for a human milestone approval. The conversion records the approval as a verified State fact with evidence.
- The source notes contained milestone boundaries as prose. The conversion split them between Invariants and Do not redo according to whether they were standing prohibitions or previously settled scope.
- The private real-world source anticipated by the brief was unavailable. The owner explicitly authorized this self-created sanitized substitute, so it tests structural fit but not privacy-redaction ergonomics.

These findings do not require changing the fixed headings or readback fields. M1 is treated as accepted by the owner's instruction to start phase 2.
