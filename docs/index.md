# RelayReady

RelayReady is a checked contract for transferring unfinished work between AI agent harnesses. Version 0.1 defines an immutable `HANDOFF.md`, a structured receiver readback, invariant hashing, and chain rules. Its original `stafeta` wire identifiers remain stable for compatibility.
