# Integrations

RelayReady ships the same L1 Writer and L2 Reader behavior through each harness's
documented native mechanism:

- `AGENTS.md.snippet`: portable project instructions.
- `codex/relayready/SKILL.md`: Codex project skill.
- `claude-code/relayready/SKILL.md`: Claude Code project skill.
- `goose/relayready.yaml`: goose recipe.
- `kimi/relayready/SKILL.md`: Kimi Code project skill.
- `chat/`: copy-and-paste prompts for chat surfaces without files or a CLI.

See `VERIFICATION.md` for the authoritative mechanism sources and the exact local
runtime checks. Runtime execution is intentionally marked unverified for tools
that were not installed; file formats are not presented as runtime evidence.

The serialized 0.1 fields keep their original `stafeta` names for compatibility.
