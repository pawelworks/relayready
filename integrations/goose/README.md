# goose integration

Use `relayready.yaml` as a project recipe, for example from `.goose/recipes/`, or
run it explicitly with `goose run --recipe relayready.yaml --interactive`.

The schema and locations were verified against official goose recipe
documentation on 2026-09-20. goose was not installed in the build environment,
so recipe validation by the goose binary and a live relay are explicitly
unverified.
