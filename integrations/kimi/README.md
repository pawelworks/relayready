# Kimi Code integration

Copy `relayready/` to `.agents/skills/relayready/` or `.kimi/skills/relayready/` in a
project. The directory form with `SKILL.md` is the documented native mechanism.

The package shape was verified against the official Kimi Code customization
documentation on 2026-09-20. Kimi was not installed in the build environment, so
runtime discovery and a live relay are explicitly unverified.
